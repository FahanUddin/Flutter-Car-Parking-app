# Car Parking Application

## Overview
A cross-platform mobile application built with Flutter for reserving parking spaces, viewing real-time availability, and navigating to selected locations.

## Features
- User authentication
- Real-time parking slot availability
- Parking reservation workflow
- Google Maps integration
- Firebase backend integration
- Cross-platform mobile interface

## Tech Stack
- Flutter
- Dart
- Firebase
- Google Maps API

## What I Learned
This project strengthened my skills in mobile app development, backend integration, real-time data handling, authentication, and user-focused application design.

## How to Run
1. Clone the repository
2. Run `flutter pub get`
3. Configure Firebase
4. Run `flutter run`
